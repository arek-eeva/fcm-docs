Git, the one that catches people

There's a small background tool called git that Claude needs in order to work on files on your own computer. You'll never open it, look at it, or think about it again. Most Macs have it already and this takes fifteen seconds. A brand new machine is exactly where it can be missing, and if it is, the fix is a big slow download that we do not want eating the front of session one. So it's worth doing now, properly, while there's no clock on you.

First, the check

  1. Press Command and Space together, type Terminal, press Enter. A small window opens with plain text in it. This is normal and you cannot break anything by typing in it.
  2. Type git --version and press Enter. Type it exactly, with the two dashes.
  3. Read what comes back.

If you get a version number

Something like git version 2.50.1. That's it, you're done. Copy that line into an email to me, close Terminal, and skip to step 2. The number itself doesn't matter, any version is fine.

If you get anything else

Either a box pops up offering to install "command line developer tools", or you get an error. Same fix either way.

  1. If the box appeared: click Install, then Agree to the licence. Skip to point 3.
  2. If no box appeared: type xcode-select --install into Terminal, press Enter, then click Install and Agree when the box comes up.
  3. Now leave it alone and let it finish. It's about 2GB, so anywhere from a few minutes to most of an hour depending on your connection. The progress bar barely moves for long stretches. That is normal and it is not stuck.
  4. If nothing seems to be happening, look behind your other windows. It's an ordinary Mac dialog and it loves opening behind Chrome. More people think this has failed for that reason than any other.
  5. When it says it's finished, go back to Terminal, type git --version again and press Enter.
  6. You should now get a version number. Copy that line into an email to me and you're done.

If it goes wrong

  • "Can't be installed at this time", or it stops partway. Almost always Apple's servers being busy rather than anything you did. Wait an hour, then type xcode-select --install again.
  • It says the tools are already installed, but git --version still fails. Stop there. There's a short fix and which one depends on your machine, so let me do it.
  • Twenty minutes in and it's still fighting you. Stop. Message me and we'll do it together on a screen share, ten minutes, I drive and you watch. This is the single most common place people get stuck, it happens to people who are perfectly good with computers, and it is not a sign of anything.

Either way, send me the line that comes back. This is the one thing I need confirmed in writing before session one, because if it's missing on the day we lose the opening stretch of the session to a download.

4. Bring your AI work across

You've done real work inside Claude and ChatGPT already, including the advisory board build. Let's carry it over rather than start cold. Paste this into each AI project 
You're helping me hand over to a new AI assistant that will run the business side of my coaching and consulting practice. Using everything you know about me and my work from our chats and this project, write a clear, plain handover brief a new assistant could read to get up to speed.

Cover these, with a heading for each:
1. About me and my work: who I am, what I do, and one line on what makes my approach distinctive.
2. What I offer and what it costs: my programs, coaching and workshops, and pricing if you know it.
3. Who I serve: my clients and audience, and the problem I help with.
4. My voice: how I write and speak, the words and tone I use, with two short examples in my style.
5. My frameworks: the models, language and structures I use with clients.
6. What we've worked on together: the projects, drafts and tasks you've helped me with, and where each is up to.
7. My recurring tasks: the things I do regularly that an assistant could take off my plate.
8. My preferences: how I like to work, and what I do and don't want from an assistant.
9. Anything else important you know about my work.

Format the whole thing as Markdown. Use # for the title and ## for each section heading. Start with a title line naming which AI tool this brief came from, and today's date underneath it.

Then save it as a Markdown file and give me a download link for it. Name the file handover-claude.md, or handover-chatgpt.md if you are ChatGPT. I want an actual .md file I can download, not just text on the screen.

If you cannot create a file for me to download, say so plainly and give me the whole thing as Markdown in one block I can copy instead. No preamble before it and no commentary after it.

Important: keep it to the business layer only. Do not include any client names, coaching notes, session detail, or anything private about the people I work with. If something can't be shared, leave it out and say so.

Then, for each one:

  1. Run it in each of your projects, in both Claude and ChatGPT. Each one remembers different things, so each will give you a different brief. Run it in an ordinary chat too, to catch anything sitting in general memory.
  2. Download the .md file it gives you and drag it into the Ingest folder. That's the whole job. Rename it if two land with the same name, otherwise leave it alone.
  3. If it tells you it can't make a file, copy the text instead, open TextEdit, and before pasting anything go to Format > Make Plain Text. That step matters, TextEdit saves in its own format otherwise and the file arrives unreadable. Paste, then File > Save with a name ending in .md, and say yes when it asks whether you really want that ending. Save it into Ingest.

If any of that turns fiddly, just paste the answers into an email to me and I'll turn them into files. It is not worth twenty minutes of your evening.

Worth setting up: talking instead of typing

Most of what Catherine needs from you isn't written down anywhere. It's in your head, and you're far faster saying it than typing it. So before we start, get dictation working and use it.

The one already on your Mac. System Settings, then Keyboard, then turn on Dictation. It gives you a shortcut key, usually pressing the microphone key or Control twice, and from then on you can talk into any text box on the machine. Free, already there, and good enough.

Or a paid one, if you'll lean on it. Something like Wispr Flow or Superwhisper is noticeably more accurate on long stretches of speech and handles the way people actually talk, with the false starts and the doubling back. Worth the small monthly cost if you're going to be dictating a lot, which I suspect you will be.

Either way, it changes how this feels. Rather than writing a brief, you talk for four minutes about how you price a Leaders Lab and why, and that recording becomes something Catherine can work from. If it's easier, dictate straight into a note and drop that into Ingest as well.
