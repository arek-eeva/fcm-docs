Install the Reader

Most of the files in this kit end in .md. That stands for Markdown, which is just a plain text file with a little light formatting: headings, bullet points, bold text. There's nothing unusual about it, but when you double-click a .md file on a Mac, it either opens as a wall of raw symbols in TextEdit or asks you to pick an app. Neither is ideal, especially once your assistant starts updating these files regularly and you want to read them easily.

The kit includes a small app called Markdown Viewer. It shows .md files in a clean, dark, easy-to-read layout, and once it's set up, every .md file opens in it automatically when you double-click. All you need to do is ask: once you're up and running, type something like "install the Markdown Viewer from the kit folder for me" and your Chief of Staff handles the rest, with no command-line steps on your part. This is Mac only.
